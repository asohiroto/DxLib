アルカナフォージ（ARCANA FORGE） v1.0.1
==========================================

戦闘の真っ最中に魔法カードを合成し、進化させて戦う、見下ろし型2Dアクションのローグライトです。

■ 起動方法
  ArcanaForge.exe をダブルクリックしてください。インストールは不要です。
  初めて「はじめから」を選ぶと、まず「訓練場」（チュートリアル）で基本操作を練習します。
  訓練場はタイトル画面からいつでも遊び直せます。

■ 動作環境
  Windows 10 / 11（64bit）、DirectX 11 対応のグラフィック
  メモリ 4GB 以上、空き容量 100MB 以上、解像度 1280x720 以上を推奨
  追加のランタイムのインストールは不要です。

■ 難易度
  拠点（タイトル →「拠点」）で選べます。タイトル画面の「はじめから」の横に現在の難易度が表示されます。
  やさしい ... 敵の攻撃力 -30%、HP -20%。アクションが苦手な方、初めての方に
  ふつう ..... 標準の難易度
  試練 1〜5 ... 「ふつう」以上を踏破するたびに解放される高難度

■ 操作（キーボード＋マウス、初期設定）
  移動 ............ W A S D
  照準 ............ マウス
  通常攻撃 ........ 左クリック
  回避 ............ Space（回避中は無敵）
  カードを使う .... 1〜4 キー、または右クリック（選択中のカード）
  隣のカードを合成  Z（1+2） / X（2+3） / C（3+4） / Q（選択中のペア）
  進化 ............ E（熟練度が最大のカード）
  ポーズ .......... Esc
  画面モード切替 .. F11
  スクリーンショット F12（セーブフォルダ内の screenshots に保存）
  キーはオプションの「キー設定」で変更できます。

■ 操作（ゲームパッド）
  左スティック：移動 / 右スティック：照準と攻撃 / A：回避
  X：選択中のカードを使う / LB・RB：カード選択 / Y：選択中のペアを合成 / B：進化 / START：ポーズ（戦闘中）

■ 遊び方のポイント
  - 同じカードを合成するとランクアップ。違うカードを合成すると、左のカードの「型」に右のカードの「属性」が乗ります。
  - 属性の組み合わせで8種類の「反応」が起きます（蒸気・爆発・溶岩・超伝導・凍土・磁砂・浄化・共鳴）。
  - 敵には弱点と耐性があります。「弱点！」と表示されたら効果的です。ボスの弱点は画面左上に表示されます。
  - 使い込んだカードは金色に光り、E キーで進化できます。
  - 鍛冶場では、2枚のカードを永続的に1枚へ「定着合成」できます（1ランに3回まで）。

■ セーブデータ
  %APPDATA%\ArcanaForge\save に保存されます（エクスプローラーのアドレス欄に貼り付けると開けます）。
  冒険は部屋をクリアするたびに自動で保存されます。
  最初からやり直したい場合は、このフォルダを削除してください。
  起動オプション --portable を付けると、exe と同じフォルダの save に保存します。

■ うまく動かないとき
  - 起動しない：グラフィックドライバを更新してください（DirectX 11 が必要です）。
    zip は必ず展開してから起動してください。
  - 「WindowsによってPCが保護されました」と表示される：署名のない個人制作ソフトのため表示されます。
    「詳細情報」→「実行」で起動できます。ウイルス対策ソフトが誤検知した場合は、除外に追加してください。
  - 強制終了した：%APPDATA%\ArcanaForge\save\crash.txt と log.txt に記録が残ります。
    不具合報告の際に添えていただけると助かります。冒険は最後にクリアした部屋から再開できます。
  - 画面が小さい／大きい：F11 でフルスクリーンとウィンドウを切り替えられます。ウィンドウの端をドラッグして大きさも変えられます。

■ AI生成物について
  カード・レリック・UIアイコンの一部は、画像生成AI（Google Gemini）で下絵を生成し、
  ドット絵の配色への変換・縮小・縁取りの加工を行っています。
  キャラクター・敵・背景・効果音・BGMは CC0 素材を使用しています（AI生成ではありません）。
  ゲームの設計とプログラムは AI アシスタント（Claude / Anthropic）で制作しました。
