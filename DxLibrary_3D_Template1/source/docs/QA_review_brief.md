# UI 検査の依頼（別モデル向け）

あなたは、販売予定の2Dゲーム「アルカナフォージ」の画面検査を担当します。前回の検査は「問題なし」と報告した直後に、利用者が実際に遊んで、拠点画面の説明文が画像と重なって読めない不具合を見つけました。甘い検査は不要です。

## 対象
下に列挙した画像（1280x720、ゲーム画面そのもの）。**1枚ずつ Read ツールで開き、等倍で全体を見てください。** 一覧化や縮小、流し見はしないこと。

## 画像ごとの必須チェック（全項目に ○ / × を付ける）
1. 文字同士の重なり
2. 文字と画像・ボタン・枠の重なり（文字が何かの下に隠れる、枠をまたぐ）
3. 文字のはみ出し・途中で切れている・画面端で切れている
4. 読めない文字（小さすぎる、背景と色が近い、豆腐（□）や欠けた文字）
5. ボタンの文字がボタンに収まっているか、何のボタンか分かるか
6. 情報の過不足（その画面で次に何をすればよいか分かるか）
7. 不自然な日本語・表記の揺れ
8. その他、販売品質として気になる点

## 出力形式（画像ごとに必ずこの形）
```
### <ファイル名>
- 1 ○/× … ×なら場所と内容
- 2 ○/× …
- 3 ○/× …
- 4 ○/× …
- 5 ○/× …
- 6 ○/× …
- 7 ○/× …
- 8 気になる点（必ず1つ以上書く。本当に何もなければ、確認した領域を具体的に書く）
- 判定：重大 / 中 / 軽微 / 問題なし（重大＝読めない・操作できない、中＝読みにくい・誤解を招く、軽微＝体裁）
```
最後に、重大・中の一覧を表にまとめてください。日本語で。ファイルは変更しないこと。

## 前提（第3回から）
- このゲームのフォント（Probly12）は 12px が本来の大きさで、次にきれいに表示できるのは 24px。戦闘 HUD の補助表示（キー名など）は 12px を使っている。12px であること自体は指摘不要だが、**実際に読めない・判別できない**場合は指摘すること。
- 英数字は意図的に全角で表示している（半角はこのフォントでは小さすぎて読めないため）。字間が広いこと自体は指摘不要。
