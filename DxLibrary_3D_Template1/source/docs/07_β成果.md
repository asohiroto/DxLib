## このフェーズで直した主な不具合
- ボスが白い塊に見える：継続ダメージで命中フラッシュが常時点灯していた → フラッシュを 0.2秒に1回までに制限し、ボスは薄く
- 敵の弱点・耐性がプレイヤーに見えなかった → 「弱点！」「耐性」の表示、ボスバーに弱点と耐性、弱点倍率 1.5→1.75、耐性倍率 0.5→0.4
- 計測方策が弱点を使っていなかった → 方策に属性相性を追加（smart とランダムの差が 4pt → 10.6pt）
- Math.Max の型の罠（カプセル画像の背景が縮まない）など、ツール側の不具合

## 正直な評価・未達
- 計測上のランダム方策は照準が自動のため、実際のでたらめなプレイより強い。smart とランダムの差は「戦略の深さ」の下限の目安として扱う
- 戦闘時間と未使用ゴールドは目標未達。マスタでの追加調整は小さく留め、仕様として記載する
- 人間によるテストプレイはできない。代わりに、自動操作の連番スクリーンショットを別モデルで評価する
- 文字列の ID 化（多言語対応）、図鑑 UI は後回し（ゲーム内のテキストは日本語のみ。ストア文に明記）
