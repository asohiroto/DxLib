# マスタ計画

## ゴール
販売できる状態の配布物（zip）を作る。クラッシュやデータ破損がなく、ライセンス表記が揃い、ストア素材が揃っている。

## β レビューへの対応（済み）
| 指摘 | 対応 |
|---|---|
| ライセンス文の同梱がない（重大） | `game/licenses/THIRD_PARTY_NOTICES.txt` を作成（DxLib 指定の著作権表示、Effekseer MIT 全文、OFL・CC0 の参照、AI 開示）。配布物に同梱する |
| ヒント帯がボタンを隠す・トーストと重なる（重大） | メニューではヒントを最下部の細い帯（y=689〜719、全ボタンより下）へ移動。トーストは画面上部の枠付き表示へ移動 |
| 自機が見えにくい・ボスのビームが画面を白く覆う（重大） | 自機マーカーを太く。発射済みビームは赤い本体＋細い芯に変更（白い全面加算をやめた） |
| 合成の HUD が分かりにくい・マナの意味が不明 | 「マナ 現在/最大」のラベルを追加。弱点・耐性の表示を追加 |
| カード名の文字サイズが不揃い | 全カード名を同じサイズに統一。進化カードは名前を金色にし、金の内枠を付けた |
| カプセル画像の焦点がない | 単色背景＋大きな魔法使い＋「火＋氷→合成」の図＋大きなタイトル＋キャッチコピーに作り直し |
| 動画がない | 30秒の MP4 と 10秒の GIF（`docs/store/`） |
| 台帳の表が崩れている | 修正 |
| バランス目標の扱い | 目標を数値で再定義（下記） |

### バランス目標の再定義（撤回。下の「マスタ計画レビューへの対応」を参照）
skill 0.6・アセンション0 の 15〜35% は、skill 0.3（初心者相当）を 5%以上に保ったまま達成できないことが計測で分かった（敵の HP・攻撃力を上げても skill 0.6 は 39% 前後、skill 0.3 だけが下がる）。そこで次のように再定義する。
- アセンション0：skill 0.3 で 5%以上、skill 0.6 で 30〜45%、skill 0.9 で 65%以下
- アセンション3：skill 0.6 で 15〜25%（高難度は段階で提供）
- 戦闘中の合成なしとの差：10pt 以上
- 現状（`docs/sim_master2.txt`）：6.0% / 39.2% / 59.5%、合成なしとの差は約 12pt（`sim_master1.txt`）
- smart とランダム方策の差は 3〜10pt で、計測のぶれの範囲。ランダム方策は照準が自動のため、深さの指標としては使わない（正直に記録）

## 作業
### M1 自動 QA（回帰）
- 自動操作で複数シード（10本）を完走させ、クラッシュ・停止・不正操作・保存の往復不一致がないこと
- 全画面のスクリーンショットを撮り、文字の重なり・はみ出しを目視で確認（タイトル、拠点、オプション、キー設定、クレジット、マップ、報酬、商店、鍛冶場、休憩所、イベント、章クリア、勝利、敗北、ポーズ、訓練場）
- セーブ：壊れたファイル、空ファイル、古い版のファイルを読み込ませて、退避と警告が出ること
- 起動場所：別のフォルダから起動しても data を見つけること（実装済み：exe の場所を基準にする）

### M2 性能
- 最も重い場面（ボス戦、弾幕、エフェクト多数）でフレーム時間を計測。60fps を保つこと

### M3 配布物
- `tools/package.ps1` で `release/ArcanaForge_v1.0.0/` と zip を作る（exe、data、README、licenses）
- 配布物のフォルダから単体で起動できること（開発用フォルダに依存しない）
- アイコン（実装済み）、ウィンドウタイトル、バージョン表記

### M4 最終レビュー
- 別モデルに配布物・ストア素材・スクリーンショットを評価させ、重大な指摘を解消する

## マスタ終了条件（＝販売レベル）
1. 自動 QA で 10本完走、クラッシュ 0、保存の不一致 0
2. 全画面のスクリーンショットに表示崩れがない
3. 配布 zip 単体で起動し、ライセンス文書が同梱されている
4. 最終レビューで重大な指摘がない

## マスタ計画レビューへの対応
| 指摘 | 対応 |
|---|---|
| セーブ場所が exe 横（Program Files で書けない） | %APPDATA%\ArcanaForge\save へ移動。旧 save からの移行、`--portable` で従来動作。ファイル操作は全てワイド文字 API（日本語ユーザー名対応）。書き込み失敗時は一時ファイルを消して旧データを保持 |
| クラッシュログがない | 未処理例外ハンドラで crash.txt（版、例外コード、exe 相対アドレス、画面名、シード、時刻）＋ダイアログ。起動・終了も log.txt に記録 |
| 起動失敗時の案内がない | DxLib／Effekseer／データ読み込みの失敗時に、原因と対処（ドライバ更新、zip の展開、data の場所）を表示 |
| 版の表記 | タイトル右下、ログ、exe の VERSIONINFO。package.ps1 は App.h と app.rc の版の一致を検査し、ファイル名にも使う |
| バランス目標の再定義はゴールポスト移動 | 撤回。「やさしい」難易度（敵の攻撃力 -30%、HP -20%）を追加し、「ふつう」を当初目標へ戻した。最終：ふつう skill 0.6 で 33.2%（目標 15〜35%）、やさしい skill 0.3 で 35.3%、試練3 で 16.7%、合成なしとの差 11.5pt（`docs/sim_master_final.txt`） |
| 未達の指標 | 既知の未達として記録：戦闘時間の中央値 約10分（目標 15〜25分）、未使用ゴールド 38%（目標 30%未満）、smart とランダム方策の差 6.5pt（目標 10pt。計測方策の照準が自動のため参考値） |
| QA の本数が少ない | 30本（3並列×10本、別シード、隔離フォルダ）に増やす |
| 保存の破損テスト | 実施済み：壊れた profile と空の run を置いて起動 → 両方 `_broken` へ退避、新規で起動、正常終了 |
| package.ps1 の不備 | 再実行時は旧出力を `_old_<時刻>` に退避。必須ファイル検査、data の取りこぼし検査、開発用ファイルの混入検査、DLL 依存検査、ZipFile による作成、SHA256 出力、日本語と空白を含むパスへの展開＋自動起動のスモークテスト |
| README の不足 | 動作環境、難易度、セーブ場所、トラブルシュート（SmartScreen・誤検知・クラッシュ時）、問い合わせ、更新履歴を追加。操作表はコードと照合（パッドの START でポーズを追加実装） |
| ウイルス対策の誤検知 | 外部サービス（VirusTotal）への送信は行わず、ローカルの Windows Defender で配布 zip をスキャンする。未署名による SmartScreen 警告への対処を README に記載 |
| 性能の数値基準 | 自動操作で「フレームの処理時間」を記録（平均、p99、最大、16.7ms 超過数）。合格基準：p99 が 16.7ms 未満 |
| クローズドテスト | 人間のテストは今回の制約で実施できない。販売前の推奨事項として成果書に記載する |
