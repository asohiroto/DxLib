# α成果報告

## 実装済み（α1〜α3）
- データ駆動：cards.tsv（基本22＋進化22、rarity・locked列）、enemies.tsv（14種：通常10＋ちびスライム＋ボス3）、rooms.tsv（各章 通常6・エリート3・ボス1）、arenas.tsv（5種）、relics.tsv（15）、events.tsv（4）
- 敵AI：追跡/アーチャー/突進/術師/分裂/自爆（予告円）/盾（耐久40、破壊で4秒無防備）/狙撃（予告線）/召喚/砲台、エリート（HP×2.2、金の縁）
- ボス：スライムキング（跳躍叩きつけ予告・分裂子・第2形態）、フロストリッチ（リング・氷柱予告・狙い撃ち）、アルカナゴーレム（突進・4〜8方向レーザー予告・被弾属性に適応耐性）
- 汎用Hazard（予告→発動）、敵生成のpendingキュー
- RunState＋Action（reducer）：Map/Battle/Reward/Shop/Forge/Rest/Event/ChapterClear/Victory/Defeat。UI・sim・自動操縦が同じ Action を送る
- マップ生成（7層×4列＋ボス、3行目は鍛冶場、最終行は休憩、商店保証）、乱数ストリーム分割（ノード単位で報酬・商店・イベントが決定論的）
- 報酬（カード3択・レリック）、商店（カード5・レリック2・回復薬・削除・強化）、鍛冶場（定着合成/ランクアップ/修練）、休憩、イベント4種
- レリック15種（Modifiersで実装）、試練（アセンション）1〜5の効果
- セーブ：RunState全体のテキスト直列化（float は %.9g で完全往復）、原子的書き込み＋.bak、破損時は退避して新規
- プロフィール（魂片・カード解放・試練解放・設定・図鑑記録）
- 画面：タイトル/拠点（解放・試練選択）/オプション（SE・BGM音量・画面モード・揺れ）/マップ/戦闘（ポーズ：再開・オプション・放棄）/報酬/商店/鍛冶場/休憩/イベント/デッキ選択・閲覧/章クリア/リザルト
- 共通フォーカスUI（キーボード・マウス・パッド・自動操縦が同じ経路）
- `--autoplay P --speed N --runs N --screenshots --fresh` で UI 経由の自動プレイ・画面ごとの撮影

## ゲート判定
| ゲート | 結果 |
|---|---|
| 1 UIだけで1ランを最後まで | 自動操縦がUI経由で全画面を通過しラン終了→タイトルまで完走（複数シード）、クラッシュ0 → **合格** |
| 2 連続ラン200でクラッシュ・進行不能0 | 方策8種×100〜300ラン（計1800ラン超）でクラッシュ0、不正Action 0（賢い方策） → **合格** |
| 3 クリア率・章別・ボス | 人間代理(skill0.6)：45.7%（300ラン）／無思考 0%／全章で死亡あり／ボス時間中央値 61・112・102秒／ボス死亡率 4%・30%・5% → **概ね合格**（スライムキングが下限5%をわずかに下回る） |
| 4 合成の価値 | 賢い 45.7% vs 戦闘中合成なし 33.0%（差12.7pt、95%CI ±7.7pt で有意）、合成を一切しなくても 40.0% → **合格** |
| 5 セーブ往復 | 全ラン全マップ到達時に save→load→再直列化一致、不一致0 → **合格** |
| 経済 | 未使用ゴールド中央値 約50%（目標25%未満）→ **未達**。AI方策がカードをあまり買わないことが主因。βで価格・商店の品揃え・人間代理方策の購買を見直す |
| 回復/被ダメ比 | 0.71（目標0.6〜0.9）→ 合格 |
| 戦闘時間合計 | 11.5分（目標15〜25分）→ **未達**（1部屋35〜40秒）。βで通常部屋の量を調整 |

## α成果レビュー（別モデル）への対応
| 指摘 | 対応 |
|---|---|
| 重大: ピッカーをESCで閉じると親画面もキャンセル | ピッカー表示中は親画面を処理しない |
| 重大: 幸運の星が永続ランクアップ | tempBoost フラグで部屋終了時に戻す |
| 重大: プロフィール読込失敗で上書き消失 | 読めないファイルは日時付きで退避・通知。.bak はセッションで1回だけ作成。進行中ランの破棄に確認ダイアログ |
| 中: セーブがindex依存 | レリック・イベントをIDで保存、部屋リストの指紋で整合確認、フェーズ・価格配列・ノード・HPを検証 |
| 中: 図鑑の敵記録が空 | 出現時に記録し RoomResult で渡す |
| 中: 画面遷移で入力が持ち越される | 画面ごとにフォーカス初期化＋0.3秒の入力ロック |
| 重大: 初期レアがヒールのみ | 雷のトーテム・吸血斬を初期解放 |
| 重大: 鍛冶の槌・三連の杖の無限マナ | 槌は「合成カードのコスト-1」に変更、三連はマナ回復を弾数で割る |
| 重大: 金の使い道・強化が未検証 | 強化価格 75+25n、AIが強化を購入（平均74G/ラン）。通常戦の金を12〜18に戻す |
| 重大: ボス曲線 | リッチ HP3600→3000・弾速↓・氷柱減、ゴーレム適応耐性を常時化＋第2形態で砲台召喚、3章雑魚HP倍率1.9→1.7 |
| 軽: 定着uid重複・祭壇の無反応・休憩表示 | 修正 |

### 再計測（skill0.6、200ラン、修正後）
勝率 39.0% ／ ボス死亡率 6%・20%・9%（全て5〜35%内）／ボス時間 67・92・123秒 ／ 回復比 0.63

### ゲート判定の訂正
- ゲート3：当初の判定で3章ボス（1〜2%）が範囲外だったことを見落としていた → 修正後は範囲内
- 「random 0〜10%」：旧 random 方策（戦闘は通常スキルで回避し、選択だけランダム）は41%で、戦略層（カード選び・商店）の影響が小さいことを示す。これはβの課題として扱う。無思考（skill0.2＋ランダム）は0%
- ゲート4：「戦闘中の合成」は有意（+12.7pt）だが、「合成を一切しない」との差（+5.7pt）は有意ではない。被ダメは合成するほうがやや多い（攻めの手段）
- クリア率の絶対値はAIの人間代理モデルによる参考値で、人間では未検証
