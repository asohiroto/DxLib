# 企画書 『アルカナフォージ』（仮題 / コード名 CardForge）  v2

## 1. 一言で
**戦いながら手札を「合成」「進化」させ、自分だけの最強カードを鍛え上げる 2D見下ろし型ローグライト・アクション。**

## 2. ターゲット / 販売形態
- PC（Windows）/ itch.io・Steam 想定、価格帯 800円前後
- 『Hades』『Enter the Gungeon』の操作感と、『Slay the Spire』のビルド構築が好きな層
- 1ラン 20〜30分、初クリアまで 5〜10時間

## 3. コアループ
```
[部屋で戦闘] ─ カードを使う／隣同士を合成する／使い込んだカードを進化させる
   ↓ クリア
[定着] この部屋で作った合成カードを1枚だけデッキに残せる（他は素材に戻る）
[報酬] カード追加 or 強化・ゴールド・（エリート）レリック
   ↓
[マップで次の部屋を選択]（戦闘 / エリート / 商店 / 鍛冶場 / イベント / 休憩）
   ↓ 各章の最後
[ボス] → 次の章（全3章）
   ↓ 死亡 or クリア
[拠点] 魂片で新カード解放・アセンション解放 → 次のランへ
```

## 4. 操作
| 操作 | KB+M | パッド |
|---|---|---|
| 移動 | WASD | 左スティック |
| 照準 | マウス | 右スティック（無入力時は最寄りの敵に自動照準） |
| 通常攻撃（無コスト） | 左クリック | RT |
| 回避ダッシュ（無敵0.25秒、CD 0.6秒） | Space / 右クリック | LT |
| カード使用（手札1〜4） | 1〜4 | X / Y / B / A |
| 合成（隣接ペア） | Shift + 1〜3（1=スロット1+2、2=2+3、3=3+4） | RB + X/Y/B |
| 進化 | E + スロット番号 | LB + ボタン |

**時間スローは使わない。** 合成・進化とも1入力で即時発動し、アクションの流れを止めない。

## 5. カードシステム（核）
### 5.1 基本
- デッキ（8〜20枚）から手札4枚。カードを使う/合成するとスロットが空き、**0.5秒後に山札から自動補充**
- 消費リソースは **マナのみ**（最大6、1.0秒で1回復）。カードコスト0〜3、合成コスト1
- 使ったカードは捨て札へ。山札が尽きたら捨て札をシャッフル
- 属性：**火・氷・雷・土 ＋ 無**（光・闇は拡張候補）
- カードの「型」：弾（射出）/ 範囲（自分中心・地点）/ 近接（斬撃）/ 設置（トラップ・壁・砲台）/ 防御（盾・回復）

### 5.2 合成（Fusion）— 隣接する2枚を1枚に
手札の隣同士のペアの間に **合成結果のプレビュー（名前・アイコン・コスト）を常時表示**。ルールは2つだけで覚えられる：
1. **同じカード同士 → ランクアップ**（★1→★2→★3、威力 ×1.6 / ×2.1、範囲・弾数も増加）
2. **違うカード同士 → 「左の型」に「右の属性」を足した複合カード**
   - 例：ファイアボール（火・弾）＋ アイスウォール（氷・設置）→ **蒸気ファイアボール**（弾・火+氷=「蒸気」反応付き）
   - 威力 = (左+右)×0.6、コスト = 左+右−1（1〜4）、合成自体は0マナ・CD0.4秒・直後0.25秒はカード使用不可。属性は最大2つまで（3つ目は上書き）
   - 属性ペアごとに固有の **反応効果** がある（4属性＋無で10通り。全組合せ定義済み＝ハズレ無し）
   - **戦闘中の合成カードは一撃の大技**：使うと素材に戻って捨て札へ。合成カードの使用では熟練度は増えない（進化と競合）

| ペア | 反応名 | 効果 |
|---|---|---|
| 火+氷 | 蒸気 | 命中地点に視界妨害の霧、敵の命中低下＋小継続ダメ |
| 火+雷 | 爆雷 | 命中で小爆発（範囲ダメ） |
| 火+土 | 溶岩 | 命中地点に燃える溶岩床 |
| 氷+雷 | 超伝導 | 凍結中の敵に命中で周囲へ連鎖 |
| 氷+土 | 永久凍土 | 命中地点が氷床、敵減速大 |
| 雷+土 | 磁砂 | 敵を命中地点へ引き寄せる |
| 同属性2枚 | 純化 | その属性の状態異常が2倍の強度 |
| 無+X | 共鳴 | 威力+30%、Xの状態異常付与率UP |

- **定着**：鍛冶場ノードでデッキの2枚を永続合成できる（ラン最大3枚、定着カードは素材に戻らず、進化・再合成不可）
- デッキ最小枚数は 6 枚

### 5.3 進化（Evolution）
- 各カードは **熟練度**（使用で+1、そのカードで撃破+1）。基本カードは 8〜12 で満タン → カードが金色に光る
- **E + スロット** で進化。0.4秒のカットイン（その間のみ無敵、時間は止めない）。進化は永続（そのラン中）
- 熟練度上限 8。進化先は1種（2分岐はMVP外）。進化で時間は止めない
- 合成中のカードは進化できない。進化済みカードも合成素材にでき、その場合「左の型」は進化後の型になる
- **判断ポイント**：「進化させて強いカードを維持」vs「熟練度を捨ててでも今合成して火力を出す」

### 5.4 状態異常と反応
- 燃焼（火：継続ダメ）/ 凍結（氷：3回氷属性で凍結＝行動停止1.5秒）/ 感電（雷：近くの敵に連鎖小ダメ）/ 重圧（土：ノックバック増・減速）
- **粉砕**：凍結中の敵に土 or 近接で×2.5（重ね掛け不可）
- 倍率上限：同一ヒットに乗る倍率は合計×3.0まで

## 6. 戦闘
- 1部屋 30〜75秒、1〜3ウェーブ全滅でクリア
- 気持ちよさ：ヒットストップ（3〜6F）、画面揺れ、ダメージ数字、撃破フラッシュ、Effekseer演出
- 視認性ルール：描画優先度は **敵弾 ＞ プレイヤー ＞ 敵 ＞ 自エフェクト ＞ ダメージ数字**。自エフェクトのアルファ上限 0.7、敵弾は縁取り付きの高コントラスト色
- 敵：10種（章ごと4種＋共通2）＋エリート（強化版）＋ボス3

## 7. ラン構造
- 1章 = 分岐マップ 10ノード（戦闘5〜6 / エリート1〜2 / 商店1 / 鍛冶場1 / イベント0〜1 / 休憩1）＋ボス
- 鍛冶場：カード1枚ランクアップ or 熟練度+50% or 任意2枚を合成定着
- レリック 15種（常時パッシブ）
- 想定時間：戦闘6部屋×60秒＋その他 → 1章 8〜10分 × 3章 = 25〜30分

## 8. メタ進行
- 魂片で解放：カードプール（初期 18 → 最大 28）、レリック、アセンション（5段階）
- 図鑑：カード・反応・敵

## 10. アート / 音 / 技術
- 解像度 1280×720（内部 640×360 ドット絵を2倍、ウィンドウ/フルスクリーン）
- キャラ・敵・タイル：itch.io の無料（CC0 推奨）ドット絵パックを **1〜2パックに限定** して統一
- カード面：**ドット絵アイコン＋属性色の枠＋ランク★** が主体（視認性優先）。アイコンは同一パック or Gemini で同一スタイル生成
- キーアート・タイトル背景：Gemini。AI生成物の使用は販売ページで開示する
- エフェクト：Effekseer（EffekseerForDXLib で直接再生）＋DxLibの加算パーティクル
- BGM/SE：itch.io 無料素材（CC0 / 商用可）。**素材台帳 docs/assets_ledger.md**（URL・作者・ライセンス・取得日）を取得時に記録
- 技術：C++20 + DxLib + EffekseerForDXLib、VSCode + MSVC（build.bat / tasks.json）
- 設計：ロジックと描画を分離。固定60fps `update()` のみで進行 → ヘッドレス自動プレイ・スクリプト入力再生・スクリーンショット自動保存

## 11. 販売レベルの定義（完了条件）
1. 起動→タイトル→ラン→クリア/死亡→拠点→次のラン が途切れず遊べる
2. MVPボリュームを満たす
3. オプション（音量・画面モード・キー確認）、セーブ/ロード（ラン中断再開）、チュートリアル、クレジット
4. ゲームパッド対応
5. クラッシュ・進行不能 0：自動プレイ 200ラン（スモーク用途）＋スクリプト入力によるUI全画面巡回
6. 面白さの検証（外部テスター不在の代替）：
   - スクリプトプレイの録画コマ（スクショ連番）を別モデルに「初見プレイヤー視点」で評価させ、主要指摘を解消
   - 指標：自動プレイ（人間相当方策）で初回クリア率 15〜35%、1部屋 30〜75秒、合成/進化の使用回数が1部屋平均1回以上
7. 全素材のライセンス確認済み、AI生成物の開示文あり
8. Release ビルドを zip 配布可能（単一exe＋dataフォルダ）
