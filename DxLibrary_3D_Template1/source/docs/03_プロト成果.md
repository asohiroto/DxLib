## プロト中の設計変更（重要）
1. **合成カードは使用すると素材に戻り捨て札へ**（一撃の大技）。旧仕様では部屋内で合成カードが循環し、デッキ10枚が手札3枚に圧縮される現象を画面で確認したため
2. 部屋クリア時の「定着」は、その部屋で作った合成から1つを選ぶ方式（World::forged、finishRoom(run, index)）
3. 合成コスト 0マナ＋クールダウン0.4秒、複合カードのコスト＝max(左,右)、威力倍率 0.75（旧：合成1マナ・コスト+1では合成するほど損になっていた）
4. 合成中（composite）のカードは進化不可（進化が分解で失われるため）
5. マジックミサイルをコスト0→1（0コスト連打の防止）

## ゲート判定
- ①合成なしでも成立：カードのみで100%クリア・57.7秒（目標30〜75秒内）→ **合格**
- ②合成・進化が有利：クリア時間は全条件で有意に短縮（57.7→41.3秒）。被ダメは skill0.3 で 35.0→24.3（CI非重複）→ **合格**
- ③UI読み取り：別モデルに4枚のスクショでチェックリスト8問。手札・カーソル・合成結果・HP・敵弾・進化可能・敵数はほぼ正答、自機位置とマナ量が不確か → 自機マーカー、マナの水位表示、数値表示、合成不可理由の具体化、カットイン縮小を実施 → **条件付き合格**

## プロト成果レビュー（別モデル）への対応
| 指摘 | 対応 |
|---|---|
| 致命: 合成が無料・常に得で判断がない | 複合コスト＝左+右−1、威力×0.6、合成カード使用では熟練度が増えない、合成後0.25秒カード使用不可、弱点×1.5。→ 賢い方策が合成を見送る割合 31%（判断が発生） |
| 致命: finishRoom未検証・欠陥 | αで定着を「鍛冶場ノード／エリート報酬」に限定し、現在のカードから再合成する方式で作り直す（α計画） |
| 重大: 計測の穴 | `--compare A B`（同シードの対比較＋95%CI）、失敗を時間上限で数える、`fuseall`（常に合成）方策を追加。連続ラン計測はαで追加 |
| 重大: 超伝導・雷連鎖が不発 | Hit.primary を導入。範囲/近接/設置でも超伝導（周囲の冷気敵が起点）・雷連鎖が発動 |
| 重大: ゾーン反応の多重発動 | ゾーンは1回だけ反応。`--reacttest`（7形×5属性=35通りをダミー敵で検証）全合格 |
| 中: ヒットストップ入力 | 最初の入力を保持、ホイール累積、ヒットストップ中も無敵時間を消化、進化で時間を止めない、状態異常キルではヒットストップなし |
| 中: 回復無制限 | 回復カードは部屋で1回使うと除外（部屋終了で戻る） |

| 中: ゲート③の条件 | Z/X/C で隣接ペア直接合成、E は進化可能カードを自動選択、使用後カーソル自動移動。αで人間モード表示の再評価 |

再計測（skill0.3, 80シード）：合成なし 56.9秒/被ダメ35.4、合成+進化 44.8秒/40.2、常に合成 47.0秒/34.7。合成は速さ（攻撃）の手段で、被ダメは減らない＝攻守のトレードオフ。

## 既知の課題（αへ持ち越し）
- AIは合成を常に選ぶ（合成がほぼ常に得）。判断の深さは「どのペアを合成するか（反応・弱点）」「進化のために温存するか」に依存。αで報酬・定着・敵の耐性で選択の幅を出す
- 1部屋の死亡率がほぼ0（AIは回避が上手い）。ラン全体での消耗で難易度を作る想定（αで計測）
- 素材は全て図形の仮素材
- カード使用回数が多い（30〜48枚/部屋）。カード1枚の重みはβで再調整
